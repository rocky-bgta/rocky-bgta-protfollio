# Nazmus Salahin Rocky — Portfolio

A lightweight, responsive portfolio for a Java Backend Engineer.

## What is included
- Intro and professional overview
- Backend, distributed systems, and data expertise
- Six linked, existing GitHub projects
- Contact and professional profile links
- Responsive layout, semantic markup, and accessible navigation
- No build tools or dependencies needed

## Run locally
Open `index.html` in any modern web browser.

## Publish on GitHub Pages
This repository includes a `.github/workflows/deploy.yml` GitHub Actions workflow. In **Settings → Pages → Build and deployment**, select **GitHub Actions** as the source. Pushes to `main` will deploy the site. The expected URL is:

https://rocky-bgta.github.io/rocky-bgta-protfollio/

## Updating
Edit `index.html` to change the biography, project descriptions, or contact links; edit `style.css` for styling. The LinkedIn button currently opens a name search rather than asserting an unverified profile URL.
